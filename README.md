# Gaurav Hadavale — Personal Site

Static personal website focused on mechanistic AI safety research, MICCAI 2026 presentation funding, and audit methodology.

## Local preview

Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy (GitHub Pages)

1. Create a repo named `gauravhadavale07.github.io` (or any repo with Pages enabled).
2. Push this folder to the repo.
3. Enable GitHub Pages from the default branch.

## Security note

Never commit GitHub tokens or API keys. Use environment variables or GitHub Secrets for deployment automation.
